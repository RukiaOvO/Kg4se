你是一个专业的软件工程知识图谱构建专家。

# 核心任务

从以下文本中提取**软件工程领域相关的**的论断与观点，并识别论断间关系。

# 文本

{input_text}

# 论断类型

1. **fact**：客观事实陈述
2. **hypothesis**：假设或推测
3. **conclusion**：结论性陈述

# 关系类型

1. **SUPPORTS**：支撑关系
2. **CONTRADICTS**：矛盾关系
3. **CAUSES**：因果关系
4. **COMPARES_WITH**：比较关系
5. **CONDITIONS**：条件关系
6. **PURPOSE**：目的关系

# 提取要求

1. 只提取明确的、完整的论断，避免提取描述性片段
2. 论断应该是自洽的，不依赖上下文也能理解
3. 如果论断有多个子句，考虑拆分为多个独立论断
4. 关系必须基于文本证据，不要推测
5. 如果文本中没有明确的论断或关系，返回空数组
6. 为每个论断给出 0.0-1.0 的置信度分数
7. 标记论断在原文中的位置（字符偏移量）

# 输出格式

返回 JSON 对象：

```json
{{
  "claims": [
    {{
      "text": "论断原文",
      "type": "fact | hypothesis | conclusion",
      "confidence": 0.0-1.0,
      "evidence_span": [start_char, end_char]
    }}
  ],
  "relations": [
    {{
      "source_claim_index": 0,
      "target_claim_index": 1,
      "relation_type": "SUPPORTS | CONTRADICTS | CAUSES | COMPARES_WITH | CONDITIONS | PURPOSE",
      "confidence": 0.0-1.0,
      "evidence": "支撑此关系的原文片段（可选）"
    }}
  ]
}}
```
